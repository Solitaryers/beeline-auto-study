================================================================
 芯位蜜线 · 考核点自动学习工具
================================================================

【怎么用】

  1. 双击  启动界面.bat          （或在命令行里运行 python beeline_gui.py）
  2. 在界面里填：账号、密码，角色保持「学生 XINWEI_PC_STUDENT」
     点「登录并保存」
  3. 勾上要学的课程（或勾「跑完全部未完成课程」），点「▶ 开始学习」

  想看进度就盯「④ 运行日志」；点「■ 停止」随时可停，下次从断点接着学。

【需要什么】

  Windows + Python 3.10 以上（自带 tkinter 即可）
  不需要安装任何第三方包，不需要浏览器，不需要 pip install

【它会做什么、不会做什么】

  会：按真实时间 1:1 把视频类考核点推到 80%（学校的达标线），
      非视频类点进去即完成，已完成的自动跳过，学完一门自动换下一门。
  不会：不加速、不跳播、不并发（服务端有反作弊，实测会被拒）；
        不自动提交试卷/作业（这类会记成「需人工」并在日志里点名）；
        不上传任何数据到别处，密码不落盘。
